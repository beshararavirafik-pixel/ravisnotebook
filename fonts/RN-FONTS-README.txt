RNLOGO.ttf — original Ravi’s Notebook wordmark. Type @ for the exact logo, or Ravi’s Notebook with standard ligatures enabled.
RNHEADER.ttf — accepted A place to grow / heading lettering.
RNBODY.ttf — accepted solid paragraph lettering (formerly Ravi Carved).

All three fonts are reusable, installable TrueType fonts with matching internal family names. RNHEADER and RNBODY also have WOFF web exports used by the website. Version 1.1 includes distinct lowercase Latin letters and accented lowercase glyphs. Color is controlled by the application.

RNLOGO and RNHEADER include outlines derived from Bodoni Moda, licensed under BodoniModa-OFL.txt. RNBODY derives from Amarante, licensed under Amarante-OFL.txt. Original source logos/lettering are preserved in assets/artwork. Build scripts are in tools.

Lowercase export: run tools/add_lowercase_fonts.py after the base build/export scripts. Uppercase outlines stay unchanged.

RNHEADER version 1.2 uses fuller lowercase strokes; uppercase artwork is unchanged.
