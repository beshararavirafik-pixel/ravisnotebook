# Event iconography

Existing painted Coptic icons selected from the public artwork catalogue of St. George Church, Nazlet El Semman. The images are stored without image edits and displayed with `object-fit: contain` so the complete scenes and any artist signatures remain visible. Related liturgical days share the appropriate feast icon.

`CREDITS.json` records the exact image URL, source page or public media-catalogue query, retrieval date, local filename, and folder mapping. Artwork authorship remains with its original iconographers; this project does not claim authorship or a public-domain licence for these works.
