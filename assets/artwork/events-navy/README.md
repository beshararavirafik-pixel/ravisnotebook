# Unified Coptic icon collection

26 original AI-generated paintings created with the built-in image tool on 2026-10-12, using the user-supplied Saint Macarius, Saint Moses, Saints Maximus and Dometius, Saint Anthony, and Good Shepherd paintings as visual style references. The shared direction is navy backgrounds, gold halos, ivory borders, warm pigments, and fine hand-painted facial and fabric texture. These are generated illustrations, not works attributed to Kirollos Kilada or another human iconographer.

`PROMPTS.json` preserves the generation prompts and the Last Supper correction. The full-resolution generated PNG masters are saved in the workspace at `outputs/icon-direction/navy-masters`; these WebP files are optimized 512 × 768 exports. Rendering preserves full paintings without cropping. Related days share the appropriate feast illustration. No earlier experimental renderings are used.
