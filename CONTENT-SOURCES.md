# Library sources

Catalogue metadata was checked on October 5, 2026. This is a static snapshot, not a live feed.

- Hymns and books: https://stgeorgesaman.com/libraries/hymns-library/ and https://stgeorgesaman.com/libraries/books/
- Reading links: https://notes.morcous.com/pages/recently-updated
- Traditional doxology texts and externally hosted recording: https://stgeorgesaman.com/libraries/hymns-library/occasionsandfeasts/holy-week/holy-thursday/matins-holy-thursday/maundy-thursday-doxology/

The Coptic and Arabic traditional liturgical text and Arabic pronunciation are attributed to the source church. English is an independent rendering of the Arabic text for study; refer to the source for its translations and textual analysis. Audio is streamed from the source host and is not stored in this repository. Book files remain on their publishers’ hosts. Catalogue cards link to their original pages.

Ravi’s existing notes, feast URLs, and browser-local editing tools are preserved. Saved items are stored only in the visitor’s browser. No sign-in or server is required.
